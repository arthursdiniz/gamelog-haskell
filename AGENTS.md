# Instruções para o Codex — GameLog

## Objetivo
Melhorar o frontend, o design gráfico e a experiência do usuário.

## Restrições
- Não alterar a lógica do backend Haskell.
- Não alterar rotas Servant ou consultas PostgreSQL.
- Não modificar o banco de dados.
- Não remover funcionalidades existentes.
- Manter o framework atual e o Lucid.
- Alterar o HTML gerado pelo Lucid apenas quando necessário.
- Usar HTML, CSS e JavaScript puro.
- Não introduzir React, Vue ou Tailwind.

## Design
- Utilizar as skills de UI/UX instaladas.
- Criar uma identidade visual própria para o GameLog.
- Priorizar legibilidade, responsividade e usabilidade.
- Revisar as páginas em desktop e mobile.
- Preservar o funcionamento de todos os formulários e botões.
